# Java Polymorphism and Interfaces

A collection of Java exercises completed as part of my Advanced Programming course. This project explores object-oriented programming concepts including polymorphism, inheritance, abstract classes, interfaces, and object composition.

## Projects Included

### Shape Hierarchy
Implemented an abstract `Shape` class with concrete subclasses such as `Circle`, `Rectangle`, and `Square`. The project demonstrates inheritance, abstract methods, method overriding, and polymorphism.

### Animal Hierarchy
Created `Animal`, `Dog`, `BigDog`, and `Cat` classes to practice inheritance, method overriding, method overloading, upcasting, downcasting, and runtime polymorphism.

### Movable Interface
Implemented the `Movable` interface using:

- MovablePoint
- MovableCircle
- MovableRectangle

to demonstrate interface implementation and object composition.

### GeometricObject & Resizable
Implemented interfaces for geometric objects and resizable shapes, including a `ResizableCircle` class.
